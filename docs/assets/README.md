# Project artwork

[`header.png`](header.png) is the README banner. Its original cloud-and-terminal mark
is part of this independent project's identity, not an Apple or OpenAI logo.

Created with OpenAI's built-in image generation tool on 2026-09-21, then revised to
use the maintainer's exact tagline. The selected PNG is committed directly; there is
no runtime image-generation dependency. Inspect the text and legibility before replacing it.
The project includes this asset under its [MIT license](../../LICENSE).

## Initial generation prompt

```text

Asset type: polished GitHub README header for the independent open-source project icloud-agent.
Create a finished wide landscape banner, approximately 3:1 aspect ratio, ideally 1536 by 512. A thoughtful, precise identity for a small developer tool, quiet and memorable, flat vector-like graphic design rendered as a crisp PNG. Deep blue-black background with a very subtle technical grid fading out. Pale cool-white typography, restrained sky-blue accent.
Main composition: on the left is an original monoline geometric cloud mark incorporating the terminal prompt >_ in its lower half; one cohesive simple mark, no Apple logo, not Apple's iCloud icon. Right of the mark, very large carefully kerned modern sans-serif lowercase wordmark reading exactly "icloud-agent". Below that, substantially smaller text reading exactly "Local tools for iCloud Mail & Calendar".
Generous negative space and margins, strong legibility at GitHub README display sizes, clean optical alignment, no microscopic details, no excessive decorative tech elements, no gradients that reduce legibility. A subtle pair of small outlined mail and calendar glyphs can appear at the far right to balance the composition. No additional text, no badges, no 3D, no mockup, no watermark. The entire banner is the artwork, edge to edge.
```
